# Create a Catalog

Creating a catalog initializes a centralized production container for a collection, seasonal drop, or marketplace launch.

---

## 1. Launch the Catalog Creation Wizard

Navigate to **Planning** or click **New Catalog Campaign** in the primary navigation:

[SCREENSHOT REQUIRED:
Page: Catalog Production (/planning?tab=catalogs)
Exact State: 'Create New Catalog' modal open with step 1 'Campaign Details' active.
Exact UI Section: Create Catalog modal window.
Recommended Crop: 750x650
Recommended Dimensions: 750x650

<Steps>
  <Step title="Campaign Title & Code">
    Enter an internal project name (e.g. *"Diwali Festive Collection 2026 - Anarkalis"*) and a campaign code prefix (e.g. `DF26-AK`).
  </Step>
  <Step title="Target Marketplaces & Presets">
    Select the primary channels where these products will be listed:
    - **Myntra Standard (4:5)**
    - **Amazon Fashion (4:5)**
    - **Nykaa Fashion (3:4)**
    - **Shopify E-Commerce (1:1 / 4:5)**
  </Step>
  <Step title="Garment Classification">
    Choose the primary garment silhouette archetype (e.g. *Ethnic Wear > Kurtas & Suits*). All child colourways inherit this classification as their baseline template.
  </Step>
  <Step title="Target Deadline">
    Set a target delivery date for internal scheduling and team notifications.
  </Step>
</Steps>

## 2. Campaign Budget & Credit Safeguards

To prevent unexpected credit overruns when launching massive catalog batches, Youthnic allows setting a **Max Credit Cap** per campaign:

[SCREENSHOT REQUIRED:
Page: Catalog Production (/planning?tab=catalogs)

Exact UI Section: Budget settings in catalog wizard.
Recommended Crop: 600x320

- **Max Credit Allocation**: Limits the total credits this catalog can consume. If the batch exceeds this cap, unrendered colourways remain in queue until an admin approves the extension.
- **Auto-Retry Allowance**: Set how many automated retries are permitted for failed poses (Recommended: `1 retry per colourway`).

---

## 3. Catalog Workspace Overview

Once created, you are directed to the **Catalog Hub**:
- **Header**: Shows campaign title, total colourways, ready count, and generation progress bar.
- **Left Column**: Shared model persona, backdrop set, and global styling rules.
- **Main Area**: Colourway grid displaying SKU cards, upload dropzones, and status tags.
