# Download Catalog Results

When all colourways in your campaign reach the **Completed** state, you can export the entire collection in an enterprise-ready archive structured for immediate marketplace upload.

---

## 1. Multi-SKU Archive Structure

Click **Export Entire Catalog (.ZIP)** on the catalog production toolbar:

## 2. Master Listing Manifest Spreadsheet

Included in every export is an auto-generated `manifest.csv` containing all commercial and technical metadata:

| Column | Example Value | Description |
| :--- | :--- | :--- |
| `parent_sku` | `YN-ANARKALI-204` | Parent collection style code |
| `child_sku` | `YN-ANARKALI-204-WNE` | Unique colourway SKU |
| `color_name` | `Wine Burgundy` | Commercial color description |
| `color_hex` | `#5B1E31` | Exact optical hex code |
| `hero_image_url` | `https://cdn.youthnic.com/exports/yn-204-01.webp` | CDN direct link for marketplace CSV upload |
| `qa_score` | `98` | Automated quality assurance score |
| `fabric_composition` | `Pure Silk Georgette with Zardozi` | Detected textile composition |

<Tip>
You can copy column URLs directly into Myntra, Nykaa, or Shopify listing upload sheets without manual re-hosting.
</Tip>

## 3. Direct Cloud Storage & Webhook Sync

Enterprise accounts can configure automatic synchronization:
- **Amazon S3 / Google Cloud Storage**: Push raw files directly into your company's private cloud bucket upon generation completion.
- **Shopify API**: Push newly generated images directly into corresponding Shopify product variant media galleries.
