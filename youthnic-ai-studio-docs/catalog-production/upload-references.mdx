# Upload Product References

Managing photo references for dozens of colorways requires structured ingestion. Youthnic AI Studio supports card-by-card drag-and-drop as well as intelligent bulk file matching.

---

On the Catalog Production board, each colourway card features dedicated dropzones for required angles:

<Steps>
  <Step title="Drop Front Reference (Mandatory)">
    Drag the front garment photo into the **Front** tile of the specific colourway. A thumbnail preview appears with a green checkmark.
  </Step>
  <Step title="Drop Back Reference (Recommended)">
    Drag the rear garment photo into the **Back** tile. If a back photo is omitted, the AI uses the shared silhouette to infer the back cut, though uploading a true back shot guarantees 100% seam fidelity.
  </Step>
  <Step title="Drop Fabric / Pattern (Optional)">
    Add a macro swatch shot if the fabric has complex texture or metallic zari threads.
  </Step>
</Steps>

### Supported Naming Pattern

Smart-Match automatically assigns roles based on filenames:

```bash
# General Pattern: [SKU]_[ROLE].[ext]
YN-ANARKALI-204-MST_front.jpg    --> Mapped to Mustard Gold (Role: Front)
YN-ANARKALI-204-MST_back.jpg     --> Mapped to Mustard Gold (Role: Back)
YN-ANARKALI-204-MST_fabric.jpg   --> Mapped to Mustard Gold (Role: Fabric)

YN-ANARKALI-204-NVY_front.png    --> Mapped to Navy Midnight (Role: Front)
YN-ANARKALI-204-NVY_back.png     --> Mapped to Navy Midnight (Role: Back)
```

<Tip>
If your filenames use custom abbreviations (e.g. `_F` for Front or `_B` for Back), you can define custom regex rules in [Admin Settings](/admin/overview).
</Tip>

## Required vs. Optional References

| Reference | Requirement Level | Impact if Omitted |
| :--- | :--- | :--- |
| **Front Image** | **Strictly Required** | Colourway cannot be generated without it. |
| **Back Image** | Highly Recommended | The AI infers back structure from the front and category rules; intricate back tassels or cuts may not match physical garment. |
| **Fabric Detail** | Optional | Subtle jacquard weaves or metallic luster may be rendered with standard fabric sheen instead of exact micro-texture. |
