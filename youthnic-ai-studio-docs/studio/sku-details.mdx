## File Naming Conventions

When you export generated catalog photos or download ZIP archives, Youthnic automatically applies a predictable, marketplace-ready naming syntax:

```bash
# Standard Single Generation Export Syntax
[SKU]_[POSE_INDEX]_[POSE_TYPE].[EXTENSION]

# Examples:
YN-KURTI-508_01_hero.webp
YN-KURTI-508_02_three-quarter.webp
YN-KURTI-508_03_back.webp
YN-KURTI-508_04_editorial.webp
YN-KURTI-508_05_detail.webp
```

If your e-commerce platform requires a custom naming pattern (such as `[SKU]-front.jpg` for Shopify or `[SKU]_f.jpg` for Amazon), you can customize the pattern in [Admin Settings](/admin/overview).

## Metadata Injection in Exports

All generated image files exported from Youthnic AI Studio include embedded EXIF/IPTC metadata:
- **Image Description**: Complete product name, detected fabric, and color hex values.
- **Copyright**: Organization legal name specified in your workspace settings.
- **Software**: `Youthnic AI Studio v2.4`.
- **Keywords / Tags**: Extracted fashion taxonomy tags (e.g. *Anarkali*, *Silk*, *Zari*, *Festive*, *Jaipur*).

<Tip>
Embedded metadata helps improve your brand's organic Google Images search visibility and automatic tagging inside enterprise Digital Asset Management (DAM) systems like Bynder or Cloudinary.
</Tip>
