# Failed Generations & Retry

While Youthnic AI Studio maintains a >97% generation success rate, intermittent cloud GPU provider outages or automated quality score rejections can occasionally cause a job to fail. 

The **Failed Generations** filter in History allows you to isolate, diagnose, and retry these jobs with zero credit loss.

```mermaid
graph LR
    A[History Archive] -->|Filter by 'Failed'| B[Isolated Failed Jobs]
    B --> C[Inspect Diagnostic Error Code]
    C --> D[Verify Automated Credit Refund]
    D --> E[Click 'Retry Job' (Routes to Healthy Worker)]
    E --> F[Successful Render & Merged into History]
```

## Understanding Failure Reasons

Click **View Error Details** on any failed card:

<AccordionGroup>
  <Accordion title="GPU_WORKER_TIMEOUT (504)" icon="clock">
    The cloud GPU node handling the latent diffusion pass experienced a hardware disconnect or exceeded the 180-second timeout ceiling.
    <br/>**Resolution**: Safe to retry immediately; will dispatch to an alternate healthy node.
  </Accordion>

  <Accordion title="QA_SCORE_DEFECTIVE (422)" icon="user-xmark">
    The rendered image failed automated quality validation (e.g. anatomical hand defect or color shift) on both its initial pass and automatic retry.
    <br/>**Resolution**: Open in Studio to inspect reference photos; adjusting prompt guidance slightly will resolve the ambiguity.
  </Accordion>

  <Accordion title="REFERENCE_IMAGE_CORRUPT (400)" icon="triangle-exclamation">
    One of the source uploaded photos contained corrupted JPEG headers or an unsupported color profile.
    <br/>**Resolution**: Re-upload the source reference in standard sRGB PNG/JPEG.
  </Accordion>
</AccordionGroup>

## 1-Click Retry Execution

Click the red **Retry Generation** button on the card:

- **Credit Exemption**: If credits were refunded upon initial failure, re-running the job consumes the original credit allocation without penalties.
- **Provider Fallback**: The retry automatically reroutes the task to an alternate backup provider if the primary provider reported downtime.
