# Inspect Generation Flow

For creative directors, technical merchandisers, and platform administrators, Youthnic AI Studio provides the **Generation Flow board** (`/history/flow/:jobId`).

The board is an interactive node canvas that rebuilds the shoot exactly as it ran, in four groups from left to right: **Input** (the uploaded product photos, the model face and the style reference), **Product analysis** (what the analysis model read and planned), **Prompting** (the stored prompt for each pose) and **Output images** (every generated frame with its own version history).

## Reading the Board

- **Header** — the SKU, the job status, the analysis model, the image model, the aspect ratio, size and quality, how many poses are done, and the cost so far (or the estimate before the run).
- **Input** — the photos the generator actually received: every product upload (front, back, bottom, fabric, mannequin, additional detail), the **Model face** card, and the style card. The style card is the backdrop authority and reads **Room only, no outfit**; when the shoot's plan matched the reference posture it reads **Room + Pose 4 posture, no outfit** (or Pose 6, or both). Its clothing, face, hair and handheld objects are never used.
- **Product analysis** — the analysis model and thinking level, its fallback models, the product facts it read (category, main colour, fabric, print, neckline and so on), the six-pose plan with the poses that copy the reference posture, and the analysis and Product DNA versions.
- **Prompting** — one card per pose with the pose line, the complete stored prompt (scroll inside the card), and chips for the photos that pose used. **Full prompt** opens it full size with a **Copy** button.
- **Output images** — the current image with its verdict (for example **DNA 95%**, **Needs review**, **Generating** or **Failed**), the thumbnails of the photos that fed it, a change note with **Run**, and a settings bar with the image model, aspect ratio, size, quality, **Download** and **More** (copy link, full prompt, open full size). The arrow next to **Run** lists the saved versions; clicking one opens that exact image full-screen, so no earlier output is ever lost.
- **Connections** — photos connect to the analysis and straight into each output image they fed; the analysis connects to every prompt; each prompt connects to its own image through its text input. Selecting any card highlights its path and fades the rest.

## Debugging a Bad Frame

If a pose came out wrong:

1. Click the pose card and check its reference thumbnails — they show exactly which photos fed that frame.
2. Open **Full prompt** to verify the stored prompt and product truth.
3. Click the earlier **version row** to compare against the previous output.
4. Type a specific change note and click **Run**. Only this pose is queued; the other five frames stay untouched.
