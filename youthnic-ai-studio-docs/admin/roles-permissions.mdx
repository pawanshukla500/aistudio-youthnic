# Roles & Permissions (RBAC)

Youthnic AI Studio implements an enterprise **Role-Based Access Control (RBAC)** architecture. This ensures employees and external contributors have exactly the privileges needed to perform their job without risking unauthorized generation spend or accidental data deletion.

## Default System Roles

<AccordionGroup>
  <Accordion title="1. Workspace Admin" icon="crown">
    Full superuser authority. Unrestricted access to all studio workflows, financial billing, credit purchases, AI model routing policies, audit logs, and user provisioning.
  </Accordion>

  <Accordion title="2. Lead Merchandiser" icon="briefcase">
    Manages seasonal collections, sets SKU quotas, links marketing calendar events to production plans, and gives commercial sign-off on completed catalog batches.
  </Accordion>

  <Accordion title="3. Stylist & Creative Lead" icon="wand-magic-sparkles">
    Curates model personas, sets architectural lighting schemes, reviews AI garment analysis outputs, and acts as the approval gate for campaign styling.
  </Accordion>

  <Accordion title="4. Studio Operator" icon="camera">
    Day-to-day execution role. Uploads reference photos, tags semantic roles (front, back, fabric), executes 5-pose photoshoots, and downloads finished assets.
  </Accordion>

  <Accordion title="5. Read-Only Viewer" icon="eye">
    Designed for marketplace catalog uploaders, external copywriters, or retail partners who only need to view historical generations and download approved assets.
  </Accordion>
</AccordionGroup>

## Creating Custom Roles

Enterprise plans can create bespoke role definitions:
1. Click **+ Create Custom Role** in the top right.
2. Enter a role name (e.g. *"Contract Retoucher"*).
3. Toggle individual permissions on or off across Studio, Catalogs, Planning, and Downloads.
4. Save and assign to specific freelance contributors.
