# Calendar Views

Youthnic AI Studio provides three specialized views to accommodate different planning horizons, from high-level quarterly roadmaps to day-by-day catalog production schedules.

---

## 1. Month Grid View

The default visual calendar. Displays the current month with multi-day event bars and single-day festive chips:

<Frame caption="Live Campaign Roadmap in Youthnic AI Studio — showing Cards view with urgent prep deadlines, regional coverage, and 1-click catalog planning">
  <img src="/images/events-live-roadmap.png" alt="Events Roadmap Cards View" />
</Frame>

- **Color-Coded Chips**:
  - <span style={{color: '#b00055', fontWeight: 600}}>Purple/Magenta</span>: Major Cultural Festivals (Diwali, Eid, Holi)
  - <span style={{color: '#f59e0b', fontWeight: 600}}>Amber/Gold</span>: Marketplace Sale Windows (Myntra EORS, Flipkart BBD)
  - <span style={{color: '#3b82f6', fontWeight: 600}}>Blue</span>: Regional State Holidays (Pongal, Bihu, Onam)
  - <span style={{color: '#10b981', fontWeight: 600}}>Green</span>: Custom Brand Launches & Drops
- **Hover Previews**: Hover over any event chip to view dates, states affected, and recommended catalog lead-time.

- **Event Date**: Depicted by a solid badge at the right end of the timeline.
- **Catalog Production Window**: Shaded progress bar spanning 30 to 60 days *before* the event.
- **Current Day Marker**: A vertical red dashed line indicating today's date, highlighting whether your production schedule is on track or falling behind.

## 3. High-Density Table View

For merchandising teams managing large spreadsheets, the **Table View** presents all events in a high-density, sortable data grid:
