## Global Event Search

Use the search input field (`Ctrl + K` or click the search box) to search by:
- **Event Name**: e.g., *"Diwali"*, *"Onam"*, *"Raksha Bandhan"*, *"EORS"*.
- **Garment Type**: e.g., *"Lehenga"*, *"Kasavu"*, *"Anarkali"*. The search engine will return events where that garment is traditionally in high demand.
- **State Name**: e.g., *"Assam"* returns *Rongali Bihu*, *Kati Bihu*, and *Bhogali Bihu*.

## Saving Custom Views

Merchandisers focusing on specific regional markets (such as a South India ethnic line) can save their filter parameters:
1. Apply your desired filters (e.g. *States: Tamil Nadu, Kerala, Karnataka, Andhra Pradesh*).
2. Click the **Save View** bookmark icon on the right side of the filter bar.
3. Give your view a name (e.g. *"South India Festive Calendar"*).
4. Access this saved view with one click from the view dropdown anytime.
