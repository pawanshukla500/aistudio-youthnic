# Event Types & Regional State Coverage

Consumer fashion buying patterns in India and global ethnic markets are deeply tied to cultural festivals and regional traditions. A saree style trending during **Durga Puja** in Kolkata differs significantly from demand during **Onam** in Kochi or **Karwa Chauth** in Delhi.

## Regional State Breakdown & Fashion Context

| State / Region | Key Tracked Events | Fashion & Apparel Context |
| :--- | :--- | :--- |
| **West Bengal & East** | Durga Puja, Kali Puja, Poila Boishakh | Red-and-white Tant/Tussar sarees, Jamdani weaves, festive kurtas, fusion Indo-western sets. |
| **Maharashtra & West** | Ganesh Chaturthi, Gudi Padwa, Navratri | Paithani sarees, Nauvari drapes, mirror-work lehenga cholis, contemporary festive kurtis. |
| **Tamil Nadu & South** | Pongal, Puthandu, Karthigai Deepam | Kanchipuram silk sarees, temple border drapes, pure zari pattu pavadai sets. |
| **Kerala** | Onam, Vishu | Kasavu sarees with gold borders, off-white settu mundu, elegant minimalist festive wear. |
| **Punjab & North** | Karwa Chauth, Lohri, Baisakhi, Teej | Heavy phulkari embroidery, bright red/magenta patiala suits, sharara sets, bridal lehengas. |
